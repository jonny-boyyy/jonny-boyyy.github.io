Privacy Policy

Last updated: November 19, 2026

Jon's Second Brain is a personal assistant app used only by its owner, Jon. It is not available to the public.

What it accesses

With the owner's permission, the app reads his own Google account data using read only access: Gmail messages, Google Calendar events, and Google Drive file details.

How data is used

The data is used only to give the owner summaries, deadline reminders, and draft replies for him to review. The app never sends email, never changes calendar events or files, and never posts anything on his behalf.

Where data is stored

Data is stored only on the owner's own Mac. It is not sold, shared, or transferred to anyone, and it is not used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the app's access at any time from his Google Account security settings.
